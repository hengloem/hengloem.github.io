# Heng LOEM - Senior Web Developer Portfolio (2025)

![Portfolio Preview](/preview-2025.png)

A modern, responsive portfolio website showcasing my skills, experience, and projects as a Senior Web Developer. Built with cutting-edge web technologies and designed for 2025 standards.

## 🚀 Features

- **Modern Design**: Clean, minimalist interface with glassmorphism effects
- **Fully Responsive**: Optimized for all devices (mobile, tablet, desktop)
- **Dark/Light Mode**: Toggle between themes with persistent preferences
- **Interactive Elements**: Smooth animations, hover effects, and micro-interactions
- **Performance Optimized**: Fast loading times and efficient code
- **Accessibility**: WCAG compliant with proper semantic HTML
- **SEO Friendly**: Optimized meta tags and structured data

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Styling**: CSS Grid, Flexbox, CSS Custom Properties
- **Icons**: [Unicons](https://iconscout.com/unicons)
- **Fonts**: [Google Fonts - Inter](https://fonts.google.com/)
- **Slider**: [Swiper.js](https://swiperjs.com/)
- **Animation**: CSS Transitions & Transformations

## 🚀 Quick Start

1. **Clone the repository**
   ```bash
   git clone https://github.com/hengloem/portfolio-2025.git
   ```

2. **Navigate to the project directory**
   ```bash
   cd portfolio-2025
   ```

3. **Open in your browser**
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js
   npx serve .
   
   # Or simply open index.html in your browser
   ```

## ⚙️ Customization

### Personal Information
Update the following in `index.html`:
- Name, title, and bio
- Contact information
- Social media links
- Work experience and education
- Project details and images

### Styling
Modify CSS variables in `assets/css/styles.css`:
```css
:root {
  --primary-color: #your-color;
  --secondary-color: #your-color;
  /* ... other variables */
}
```

### Content
- Replace images in `assets/img/`
- Update project descriptions and links
- Modify skill percentages and categories
- Add/remove portfolio items
